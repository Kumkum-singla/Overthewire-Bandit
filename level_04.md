# Bandit Level 3 → Level 4

## Objective

Retrieve the password for Bandit Level 4 from the hidden file inside the `inhere` directory.

## Commands Used

```bash
cd inhere
ls -a
cat ...Hiding-From-You
```

## What I Learned

- How to navigate directories using the `cd` command.
- Hidden files begin with a `.` (dot).
- The `ls -a` command displays hidden files along with regular files.

## Key Takeaway

The `ls -a` command is essential when searching for hidden files because the normal `ls` command does not display them.
