# Bandit Level 0 → Level 1

## Objective

Retrieve the password for Bandit Level 1 by reading the contents of the `readme` file.

## Command Used

```bash
cat readme
```

## What I Learned

- How to display the contents of a file using the `cat` command.
- Files in the current directory can be accessed directly by their filename.
- Reading files from the terminal is one of the most basic Linux skills.

## Key Takeaway

The `cat` command is a simple and effective way to read the contents of text files in Linux.
